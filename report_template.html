Bagian 2 — Analisis Komparatif Platform

Berikut adalah perbandingan mendalam antara platform Web, Desktop, dan Mobile berdasarkan enam aspek fundamental arsitektur dan rekayasa perangkat lunak:

Aspek Platform Web Platform Desktop Platform Mobile
Bahasa Utama HTML untuk struktur dokumen, CSS untuk styling visual, serta JavaScript/TypeScript untuk logika interaktif sisi klien. Bagian backend menggunakan Node.js, Python, Go, Java, atau PHP. [1][2] Bergantung pada OS target: C#/.NET dan C++ pada Windows, Swift/Objective-C pada macOS, C++/GTK pada Linux. Solusi multiplatform memakai Electron (JS/HTML/CSS), Qt, atau Flutter Desktop. [3][4] Kotlin dan Java untuk Android; Swift dan Objective-C untuk Apple iOS. Pengembangan multiplatform populer memakai Dart (Flutter) atau JavaScript/TypeScript (React Native). [5][6]
Arsitektur Model client-server terdistribusi. Browser bertindak sebagai thin client yang merender halaman dan berkomunikasi dengan server melalui protokol HTTP/HTTPS atau WebSocket. [2] Aplikasi monolitik atau klien kaya (thick client) yang dieksekusi langsung oleh OS komputer. Memproses data lokal, mengakses sistem berkas, dan dapat bekerja offline penuh. [3][4] Aplikasi terinstal pada sandboxed OS mobile. Mengakses subsistem perangkat keras melalui API berizin (kamera, GPS, sensor gerak, push notification). [5][6]
Cara Distribusi Dihosting pada web server/cloud dan diakses via URL melalui browser. Pembaruan bersifat instan dan terpusat tanpa memerlukan instalasi di sisi pengguna. [1][2] Didistribusikan melalui installer (.exe, .msi, .dmg), repositori paket (deb/rpm), atau toko aplikasi (Microsoft Store). Pembaruan membutuhkan proses patching/unduhan ulang. [3][4] Didistribusikan melalui toko aplikasi terkurasi (Google Play Store, Apple App Store). Memerlukan proses peninjauan (review) ketat serta unduhan pembaruan oleh pengguna. [5][7]
Keunggulan Aksesibilitas universal di berbagai perangkat, zero-installation, pemeliharaan dan deployment terpusat, serta efisiensi rilis fitur baru kepada seluruh pengguna sekaligus. Kinerja komputasi maksimal, pemanfaatan penuh CPU/GPU multi-core, akses hardware mendalam, responsivitas tinggi, serta kemampuan kerja offline tanpa hambatan jaringan. Portabilitas tinggi (selalu dalam genggaman), integrasi sensor fisik kontekstual (lokasi realtime, biometrik, kamera), serta kemampuan push notification yang interaktif.
Keterbatasan Ketergantungan tinggi pada konektivitas jaringan, performa komputasi berat terbatas oleh sandbox browser, serta kompatibilitas antar-browser yang bervariasi. Kompatibilitas antar-OS memerlukan penyesuaian kode, ukuran installer relatif besar, dan pembaruan versi memerlukan interaksi manual pengguna. Keterbatasan daya baterai dan memori, variasi ukuran layar (fragmentasi), masa persetujuan rilis toko aplikasi yang lama, serta proteksi izin perangkat yang ketat.
Contoh Aplikasi Gmail Web, Google Docs, Trello, Figma Web, portal akademik kampus. Visual Studio Code Desktop, Adobe Premiere Pro, AutoCAD, Microsoft Word Desktop. Google Maps Mobile, WhatsApp Mobile, Gojek/Grab, Mobile Banking (BCA/Mandiri).
Kesimpulan Pemilihan Platform:

Setiap platform memiliki kekuatan unik yang disesuaikan dengan kebutuhan domain. Platform Web adalah pilihan paling ideal untuk sistem informasi yang membutuhkan akses universal dan siklus deployment cepat. Platform Desktop menjadi pilihan mutlak untuk aplikasi yang membutuhkan komputasi berat, manipulasi file lokal intensif, dan latensi rendah. Sementara itu, platform Mobile unggul pada layanan yang mengutamakan mobilitas, konteks lokasi nyata, dan interaksi personal harian. Arsitektur modern kerap mengombinasikan ketiga platform melalui backend API terpadu.

Bagian 3 — Refleksi Pembelajaran & Setup Environment

Refleksi pribadi mengenai minat platform, kendala dalam penyiapan lingkungan kerja, serta rencana perbaikan berkelanjutan:

Bagi saya, platform Web merupakan platform yang paling menarik untuk dipelajari karena saya ingin memahami proses pengembangan aplikasi secara menyeluruh, mulai dari merancang tampilan, menghubungkan frontend dengan backend, mengelola data, sampai melakukan deployment agar aplikasi dapat digunakan melalui browser. Saya tertarik bukan hanya membuat aplikasi terlihat bagus, tetapi juga memahami bagaimana aplikasi bekerja dan menyelesaikan kebutuhan penggunanya.

Menurut saya, salah satu hal penting dalam mempelajari Pemrograman Berbasis Platform adalah memahami bahwa setiap platform mempunyai karakteristik, keunggulan, dan keterbatasan yang berbeda. Web menawarkan kemudahan akses dan pembaruan terpusat, sedangkan Desktop dan Mobile mempunyai kelebihan tersendiri sesuai kebutuhan pengguna dan kemampuan perangkatnya.

Tantangan dalam menyiapkan environment pengembangan adalah memastikan setiap tools yang diperlukan tersedia, dapat dikenali oleh terminal, dan mempunyai versi yang sesuai. Saya perlu memverifikasi kondisi sebenarnya melalui perintah terminal, membaca pesan kesalahan dengan teliti, serta memeriksa dokumentasi resmi apabila muncul masalah. Saya tidak ingin hanya mengikuti langkah instalasi tanpa memahami hasilnya.

Ke depannya, saya akan membiasakan diri mengerjakan proyek secara bertahap, menguji setiap perubahan, mencatat masalah dan solusinya, serta menggunakan Git dan GitHub untuk mengelola versi kode. Saya juga ingin meningkatkan kemampuan membangun aplikasi dari tahap perencanaan hingga deployment. Dengan cara tersebut, saya berharap dapat menjadi pengembang yang tidak hanya mampu menulis kode, tetapi juga memahami proses pengembangan dan pemeliharaan aplikasi secara bertanggung jawab.
