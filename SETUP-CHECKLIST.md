# Checklist Setup Environment — Pertemuan 1

Gunakan checklist ini saat memeriksa environment di komputer yang digunakan untuk kuliah. Catat hasil aktual; jangan mengisi status berdasarkan perkiraan.

## Pemeriksaan terminal

Jalankan satu per satu di terminal/CMD:

```bash
git --version
node --version
npm --version
java -version
```

| Tool | Hasil aktual | Status |
|---|---|---|
| Git | Isi setelah perintah dijalankan | Belum diverifikasi |
| Node.js | Isi setelah perintah dijalankan | Belum diverifikasi |
| NPM | Isi setelah perintah dijalankan | Belum diverifikasi |
| Java JDK | Isi setelah perintah dijalankan | Belum diverifikasi |
| Visual Studio Code | Konfirmasi apakah sudah terpasang | Belum dikonfirmasi |
| Android Studio | Konfirmasi terpasang/belum dan kendala jika ada | Belum dikonfirmasi |

## Bukti screenshot

- Ambil screenshot langsung dari terminal setelah perintah versi dijalankan.
- Pastikan perintah dan hasilnya terbaca dalam gambar.
- Jangan membuat ulang hasil terminal menggunakan editor gambar atau teks buatan.
- Simpan screenshot asli ke folder lokal repository, misalnya `docs/screenshots/`, sebelum menyusun laporan PDF.
- Hindari memasukkan informasi sensitif yang tidak diperlukan ke dalam screenshot.

Checklist ini membantu persiapan, tetapi bukan pengganti screenshot asli yang diminta dalam laporan.
